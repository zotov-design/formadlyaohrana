# Форма для охраны — макет V1

Готовая статическая сборка сайта: HTML, CSS, JavaScript, шрифты, фотографии и анимации.

Демонстрация на GitHub Pages: https://zotov-design.github.io/formadlyaohrana/v1-site/

## Локальный просмотр

Установите Node.js и запустите из корня репозитория:

```sh
node v1-site/serve.mjs
```

Откройте http://127.0.0.1:3100/formadlyaohrana/v1-site/.

Устанавливать зависимости и собирать проект не требуется. GitHub Pages публикует корень репозитория; файлы V1 находятся в `v1-site`. Папки `_next`, `fonts` и `v1` внутри неё необходимы для работы сайта.

Это макет: серверные заказы и оплата не реализованы. Часть ссылок ведёт на действующий магазин formaohrana.ru.

В HTML установлен `noindex, nofollow`. Файл `_headers` задаёт такой же HTTP-заголовок на поддерживающих его хостингах; локальный сервер также возвращает этот заголовок.

Включены последние правки: выпадающие каталог и услуги, мобильный хедер, появление блоков при прокрутке, кольцевой слайдер товаров, заголовок популярных товаров без поясняющей строки.
