# Форма для охраны — V2

Статический демонстрационный макет из forma-ohrana-v2.zip.

GitHub Pages: https://zotov-design.github.io/formadlyaohrana/

Публикация: Settings → Pages → Deploy from a branch → main → / (root). Файл .nojekyll сохраняет каталог _next.

Поиск и корзина демонстрационные; оплаты и серверных заказов нет. Ссылки разделов ведут в действующий магазин formaohrana.ru.

Для макета добавлен noindex,nofollow, как у ранее опубликованной версии V1.

## Версия V1

Текущий макет V1 находится в [v1-site](v1-site/README.md). Для локального просмотра: `node v1-site/serve.mjs`; для размещения как отдельного статического сайта используйте папку `v1-site` как корень публикации.
